# EL BARBERO — Site e agendamento

Projeto de site responsivo e sistema de agendamento da El Barbero Barbearia — Dom Pedro, Manaus/AM.

## Documentos de especificação
- `PROMPT.md`: requisitos funcionais, técnicos, visuais, SEO, segurança e critérios de aceite.
- `AGENTS.md`: instruções permanentes para o Codex.
- `TASKS.md`: fases de execução e checklists.

## Antes de programar
1. Leia os três documentos.
2. Siga uma fase por vez.
3. Não coloque segredos no Git.
4. Não faça deploy nem altere banco de produção sem autorização explícita.

## Dados comerciais
Serviços, preços, duração, barbeiros, horários excepcionais, políticas e credenciais de integração precisam ser confirmados antes da publicação.

## Stack alvo
PHP 8.3, MySQL/InnoDB, PDO, HTML/CSS/JavaScript e PWA. Fuso: `America/Manaus`.

## Espaços reservados
A especificação prevê 10 posições de serviços e 5 posições de barbeiros. Dados e fotos reais serão inseridos depois. Qualquer serviço fictício ou retrato temporário é apenas material de demonstração e não pode ser publicado como informação real.
